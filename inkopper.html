Application Password aanmaken
  1. WordPress-admin → Gebruikers → klik je user (bv. inkopper)
  2. Scroll naar Application Passwords
  3. Geef het een naam (bv. In-Kopper) en klik op Nieuw application password toevoegen
  4. WordPress toont eenmalig een 24-tekens code (xxxx xxxx xxxx xxxx xxxx xxxx) — kopieer 'm en bewaar in je password manager
  5. Plak die code in het Application Password-veld hierboven (1Password/Keychain kan 'm volgende keer automatisch invullen)
